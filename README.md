# Awaken

A small macOS menu bar utility to keep your Mac awake and monitor remaining model quotas.

一个轻量的 macOS 菜单栏工具：一键保持唤醒、定时恢复休眠，查看 Codex、Gemini（Antigravity）和 Kimi 的剩余额度。

- macOS 13+，支持 Apple Silicon 和 Intel。
- 左键展开菜单，右键切换保持唤醒。
- 默认 Control + Shift + U 打开菜单；菜单内 A / D / R 分别切换保持唤醒、屏幕常亮和刷新额度。
- 支持中英文、日月图标和圆形文字显示。
- 额度监控为可选功能，需要使用者连接自己的账号。
